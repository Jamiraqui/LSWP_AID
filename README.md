# LSWP Aid Student Guide

Student-facing Lasallian Student Welfare Program Aid website. It includes the
application form, downloadable application-letter template, eligibility and
document checklist, and the two application tracks.

## Deploy to Vercel

This is a standard Next.js project. Import the project into Vercel or upload
the contents of the supplied ZIP as a project. Vercel will use the included
`vercel.json` configuration and run the production build automatically.

## Local development

```bash
pnpm install
pnpm dev
```

Run `pnpm build` to verify the production build.
